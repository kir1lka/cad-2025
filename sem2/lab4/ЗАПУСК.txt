Лабораторная №4. Spring Boot и PostgreSQL

Запуск готовой версии на этом ПК:
1. Откройте Docker Desktop и дождитесь запуска движка.
2. Откройте start-lab4.bat.
3. Перейдите на http://localhost:8084/login.

Для готового JAR нужна Java 17. Для сборки из исходников также нужен Node.js.
Скрипт запускает PostgreSQL через docker compose и готовый JAR из build/libs.
Данные хранятся в томе raspisa-lab4_lab4_pgdata, общем для обеих копий lab4.
Остановка приложения: Ctrl+C в его окне.
Остановка базы: docker compose stop db
Повторная сборка: .\gradlew.bat bootJar
Запуск через Gradle: сначала docker compose up -d --wait db, затем .\gradlew.bat bootRun

Учебные пользователи:
admin / Admin!2026 – вся панель и история входов
teacher / Teacher!2026 – журнал
student / Student!2026 – просмотр мероприятий
methodist / Methodist!2026 – мероприятия и задачи подготовки

PostgreSQL для pgAdmin, DBeaver или другого клиента:
Host: localhost
Port: 5544
Database: raspisa_lab4
Username: raspisa
Password: Lab4!2026
JDBC: jdbc:postgresql://localhost:5544/raspisa_lab4

Внутри контейнера порт 5432. На ПК используется 5544.
Параметры приложения можно задать через DB_URL, DB_USERNAME, DB_PASSWORD и SERVER_PORT.
При первом запуске Docker создаёт пользователя и базу. Смена пароля в .env после создания тома
не меняет пароль существующего пользователя PostgreSQL.

Если порт 8084 занят: $env:SERVER_PORT='8085'; .\gradlew.bat bootRun
Не запускайте одновременно готовый JAR и bootRun на одном порту.

Локальный пример с задачей сохранён в базе этого ПК. При создании новой базы
добавьте задачу через раздел «Подготовка мероприятий» – приложение создаёт только справочники
и учебные аккаунты, а рабочие задачи вводятся через форму.

Запасной режим без PostgreSQL:
$env:SPRING_PROFILES_ACTIVE='h2'; .\gradlew.bat bootRun
Для возвращения к PostgreSQL: Remove-Item Env:SPRING_PROFILES_ACTIVE
Этот режим использует другую базу и не заменяет PostgreSQL для сдачи лабораторной №4.
