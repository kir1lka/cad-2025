## Запуск

Требуется JDK 17. Gradle скачивается через Wrapper при первом запуске.

Из папки `sem2/lab1` в PowerShell:

```powershell
.\gradlew.bat bootRun
```

В Linux или Google Colab:

```bash
bash gradlew bootRun
```

Приложение доступно по адресу <http://localhost:8080>.
Сообщения хранятся в памяти и удаляются после остановки приложения.

## Запросы

| Метод | Адрес | Действие |
| --- | --- | --- |
| GET | `/` | Приветствие |
| GET | `/messages` | Получить все сообщения |
| POST | `/messages` | Добавить сообщение |
| PUT | `/messages/{index}` | Изменить сообщение |
| DELETE | `/messages/{index}` | Удалить сообщение |
| DELETE | `/messages` | Очистить все сообщения, дополнительное задание 1 |
| GET | `/messages/count` | Подсчитать сообщения, дополнительное задание 6 |

Индексы начинаются с нуля. При добавлении и изменении сообщения передаётся
обычный текст с типом `text/plain; charset=utf-8`.
При неверном индексе приложение возвращает текст `Message not found at index N`
с кодом 200, как в примере методички. После удаления индексы оставшихся
сообщений сдвигаются.

## Проверка

```powershell
.\gradlew.bat test bootJar
```

Проверяются основные операции с сообщениями, очистка и подсчёт,
а также изменение и удаление по неверному индексу.
